# Phase 7 Workspace Intelligence Walkthrough

Every project surface includes an ambient Narrative Intelligence banner. It reuses the cached analysis snapshot to surface the most relevant warning for the current workspace without reanalyzing the novel.

Choose **Explain** to open the companion's **Context** tab. Each recommendation includes severity, affected chapters/scenes, suggested action, and **Why was this generated?**. The explanation exposes the originating rule/category, exact evidence, contributing graph nodes, canon and timeline references, confidence, and analysis identifier.

Chapter, scene, dialogue, and dashboard recommendations all consume the same Narrative Analysis findings used by Story Health. Resolving the underlying finding therefore updates every consumer on the next analysis refresh.
