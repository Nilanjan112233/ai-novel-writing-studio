# RC5 Knowledge Graph UX Walkthrough

The Knowledge Graph still uses Narrative Analysis nodes and edges as its only graph source. RC5 changes presentation and interaction, not graph ownership.

## Walkthrough

1. Open **Knowledge Graph** from the Understand group.
2. Search by entity name or filter by readable type.
3. Select a labeled node to open its structured inspector card.
4. Review name, type, summary, status, importance, warnings, connected entities, chapters, Story Timeline references, canon references, and Story Health impact.
5. Use **Center here** to focus the neighborhood.
6. Expand progressively instead of loading an unreadable full-novel graph at once.
7. Use Explain/Open/Navigate actions to reach the owning workspace and evidence.

Raw objects, source collections, node identifiers, internal metadata, and JSON payloads are not rendered in the author view. Search serialization may occur internally, but it is never displayed.
