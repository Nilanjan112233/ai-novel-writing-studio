# Phase 7 AI Project Assistant Walkthrough

Open **AI Narrative Companion** from any project workspace. Choose one of six modes: Story Coach, Developmental Editor, Character Interviewer, Continuity Expert, Worldbuilding Consultant, or Dialogue Coach.

The assistant answers from the current Narrative Analysis snapshot and labels each response with its evidence-link count and analysis identifier. Requests such as `Open Chapter 12`, `Show canon conflicts`, `Which mysteries remain unresolved?`, or `Explain Timeline Warning #7` return both an evidence-grounded answer and typed navigation buttons. Selecting a button moves directly to the requested workspace surface.

Mode changes alter the review lens, not the underlying facts. Assistant messages persist as project history with the provider/model metadata, execution trace, evidence identifiers, and proposed canon fact identifiers.
