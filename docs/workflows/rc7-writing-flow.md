# Writing and Revision Workflow

## From a plan to approved prose

1. Open **Write > Drafting**.
2. Check the Writing Desk for the current scene and next action.
3. If planning checks are open, either follow the exact links back to planning
   or create a clearly labelled exploratory draft.
4. Read any **Before final prose** coaching. If another scene has the same
   purpose, conflict, and outcome, differentiate the plan before investing in
   a final draft.
5. Select **Generate draft**. NovelForge shows why the draft was created, what
   it is expected to improve, what context it used, and what should remain
   unchanged.
6. Check its goal, trouble, stakes, connection from the previous scene, new
   progression, and handoff to the next scene.
7. Read the draft. Move it to review when it is ready for focused work.
8. Choose a writing operation for a whole-scene alternative, or open
   **Review > Editorial** for a structured revision pass.
9. Compare Version A, B, or C. Favorite promising alternatives, or combine
   selected text into a new review version.
10. Approve only after the existing continuity and planning checks pass.
11. Follow **Continue writing** to the next planned scene.

## Writing operations

Whole-scene alternatives support rewrite, expand, condense, dialogue, pacing,
emotion, tension, description, action, humor, mystery, horror, romance, world
detail, internal thoughts, and transitions.

Each operation returns an explanation:

- why the suggestion exists;
- expected narrative impact;
- affected narrative areas;
- estimated scope;
- elements intended to remain unchanged;
- story evidence used.

## Writer's Room

Writer's Room creates three independent possibilities by default:

- a more emotional direction;
- a more action-oriented direction;
- a more mysterious direction.

NovelForge explains the trade-off and never selects a winner. The author can
compare, favorite, discard, revise, or merge the options.

## Revision passes

Use Editorial for development, line, copy, style, continuity, dialogue,
emotion, description, consistency, or grammar work. A generated revision is a
proposal. Approving its branch does not overwrite prose; **Use as new draft
version** creates a protected review version with complete lineage.

## Recovering work

- Paragraph autosave and paragraph version history remain available in the
  existing Paragraph Editor.
- Whole-scene alternatives remain in Scene Version History.
- Rollback restores an earlier scene or chapter draft as the active version.
- Revision source snapshots remain immutable.
- A merge always creates another version.

If a save or provider request fails, retry from the visible error state.
Request identity prevents the same action from creating duplicate drafts.

## When NovelForge corrects an AI response

NovelForge validates generated prose against the same planning and narrative
authority rules used by the rest of the application before storing it. If the
provider introduces a participant or fact outside the approved scene
authority, it gets one corrective attempt. If correction still fails, the
generation stops with a friendly retry message and the previous prose stays
untouched. New stable facts that are allowed as proposals appear in the Canon
Queue; they never become canon automatically.
