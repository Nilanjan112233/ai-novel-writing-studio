# Development reports (archive)

These files are the working notes produced while NovelForge was being built,
mostly with AI coding assistants. Each development phase ended with a plan,
an implementation report, end-to-end results, and known limitations. They are
kept for traceability; they are **not** the place to start reading.

Start with the [project README](../../README.md) and
[How NovelForge works](../HOW_IT_WORKS.md) instead.

| Folder | What is inside |
| --- | --- |
| [`phases/`](phases/) | Plans, completion reports and E2E results for phases 1A–7 (the first feature build-out). |
| [`releases/`](releases/) | Release-candidate reports RC5–RC9: hardening, UX audits, test results, known limitations. |
| [`memory-research/`](memory-research/) | Experiments on long-novel memory and retrieval (lexical/semantic retrieval, rank fusion, context cost, benchmarks). |
| [`product-audits/`](product-audits/) | Architecture, database, product and writing-quality audits, plus feature-specific reports. |

Numbers in these reports (benchmarks, costs, test counts) describe the code at
the time each report was written and may be out of date.
