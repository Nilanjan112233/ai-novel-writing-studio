# Experience Completion Known Limitations

1. Critique combines deterministic evidence with the latest available AI reviewer output. Subtle thematic or emotional problems may remain undetected when chapter intelligence is sparse.
2. Shared Context classification is intentionally conservative. Ambiguous chat, questions, and navigation commands are not persisted automatically; authors can use the explicit structured-context endpoint when a nuanced fact matters.
3. Legacy canon entries expose only the history that was originally recorded. Canon Explorer cannot reconstruct approval events that predate governance persistence.
4. Milestone criteria use product defaults. Genre-specific exceptions can be represented as not applicable, but project-defined gate templates are not yet configurable in the UI.
5. The companion uses restrained motion and an event feed rather than a freely roaming avatar. This protects focus and accessibility, but it is less theatrical than a game-style character.
6. Narrative source loading is bounded to 20,000 records per source collection. This is well above the 500-chapter target but is a documented ceiling for unusually fragmented projects.
7. Real-provider regression duration and output structure depend on Google AI Studio availability. Deterministic mock-provider suites remain the repeatable CI baseline; live Gemini validation is an additional integration gate.

None of these limitations bypass canon approval, alter the Paragraph Editor, or create duplicate narrative-analysis logic.
