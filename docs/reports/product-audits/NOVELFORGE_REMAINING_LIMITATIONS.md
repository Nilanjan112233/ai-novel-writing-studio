# NovelForge Remaining Limitations

1. The live Chapter 1 sample was 1,492 words against a requested 1,000-1,200 range. The source now adds bounded compression after scene-sized correction, but a new real-provider range matrix is still required to prove compliance across providers and sizes.
2. Humanization is safely versioned and routed, but this pass did not run a fresh real A/B prose comparison. Literary improvement must be judged from paired samples, not from the presence of a prompt.
3. Gemini 3.1 succeeded for a Story Studio assistant call but still failed one strict structured planning call and escalated to DeepSeek. The fallback is safe; structured-output reliability is not yet fully optimized.
4. The measured real cost baseline is recorded, but a matched after-routing percentage reduction was not established. Do not claim savings until extraction, humanization, brainstorming, and prose are benchmarked on equivalent inputs.
5. Selection-based AI editing is implemented over the existing Editorial path, but its complete real-provider browser loop was not exercised in this final pass.
6. The existing project retains a continuity warning from its earlier real run. New validation blocks the known duration contradiction before approval; it does not rewrite historical prose automatically.
7. The Story Studio page remains an incremental chat/workspace hybrid. History is progressively disclosed, but a future visual pass could make clarification and revision turns feel more inline.
8. The root test wrapper still times out in this environment. All 182 backend tests were completed through split commands, while the wrapper itself was not reported as passed.
9. No TencentDB Agent Memory integration was added. Native retrieval and authority remain sufficient for this scope and should be benchmarked further before considering an adapter.

These limitations do not weaken the author-control boundary: ambiguous requests do not mutate state, approved prose remains immutable, revision output is reviewable, and fallback output is validated before use.
