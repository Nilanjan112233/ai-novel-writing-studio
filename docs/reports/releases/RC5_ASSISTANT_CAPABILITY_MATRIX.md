| Question or command | Reasoning layer | Result | Navigation |
|---|---|---|---|
| What does Arc Board do? | Application | Purpose, value, task, and next step | Arc Board; Arc Development |
| Explain this page | Application | Current-surface guidance | Current and downstream surfaces |
| What does Run Cycle do? | Application | Author-language workflow explanation | Project Activity |
| Where do I approve Canon? | Application | Canon proposal workflow | Canon Queue |
| How do I publish? | Application | Manuscript and readiness path | Manuscript; Readiness |
| Why is Story Health 82? | Project | Score evidence from existing analysis | Story Health and responsible workspaces |
| Which mysteries remain unresolved? | Project | Grounded plot-thread evidence | Mysteries or Plot Threads |
| Summarize Character Alice | Project | Character Intelligence evidence | Characters |
| Open Chapter 12 | Combined navigation | Project-aware chapter action | Governed Drafting |
| What should I do next? | Project workflow | Narrative Completeness next action | Exact recommended destination |

Application questions are answered without story search or provider cost. Project conclusions retain evidence. Combined questions use the two layers explicitly rather than blending application help into story evidence.
