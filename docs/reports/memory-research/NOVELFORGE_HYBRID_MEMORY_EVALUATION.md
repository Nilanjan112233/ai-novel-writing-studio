# Hybrid Memory Evaluation

## Candidate hybrid

The safest possible hybrid is already represented by the boundary:

- Native structured/authority-aware memory for canon, decisions, Story Bible, Narrative Intelligence, approved prose, chronology, and writing context;
- Tencent, if later proven useful, for long conversation/workflow summaries and agent execution history;
- Native fallback for every Tencent failure.

## Current evidence

Tencent capture works, but the tested local gateway returned zero recall. Therefore there is no evidence yet that the hybrid improves context size, latency, provider cost, or prose continuity. The current `benchmark` mode keeps Native as primary and records Tencent observational comparisons, which is the correct safe default for experiments.

## Recommendation

Do not activate a Tencent-assisted hybrid for normal writing until a populated retrieval benchmark shows lower important-memory miss rate, no increase in stale/rejected/chronology leakage, comparable or better prose continuity, acceptable latency, and a measurable token or cost benefit.
