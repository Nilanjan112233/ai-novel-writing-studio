# Story Studio Memory Comparison

The current Story Studio capture path is dual-observable and preserves Native as the writing/authority path. Browser acceptance on the real ten-chapter project showed Story Studio reporting “Your story has 10 chapters” and “Chapter 10 is the latest approved chapter.”

This Tencent enablement pass did not run a new 20–50-turn blind Story Studio answer-quality study. It did prove that L0 conversation search works after the runtime/configuration repair, but not that Tencent improves long conversation intent resolution, rejection handling, or answer quality over Native. Those claims remain unproven and are intentionally not used to justify a default change.
