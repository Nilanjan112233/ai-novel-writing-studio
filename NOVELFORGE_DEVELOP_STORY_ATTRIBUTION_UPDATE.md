# NovelForge Develop Story Attribution Update

Phase A removes Narrative Studio's three full-project index refresh points. It does not redesign specialist packets.

The provider-free replay of existing cycles 2 and 3 found 25 specialist packets totaling 2,480,202 estimated prompt tokens, median 97,463. Individual packets range from 32,632 to 167,950 tokens. Retrieved Native memory accounts for roughly 2,633–3,680 tokens per packet, so the dominant growth is outside Native recall and remains in the repeated broader workflow/agent/story context.

Historical packets predate complete per-source prompt attribution (`historical_attribution_complete=false`), so Story Bible section, previous-agent output, workflow, and authority overlap cannot be reconstructed exactly. No paid cycles were run merely to fill that gap. New context packets retain the P0 attribution fields for a future controlled Phase E benchmark.

Conclusion: Phase A removes indexing work from specialist calls, but does not materially solve the 2.48M-token packet problem. This evidence strongly supports Phase E next, using role-specific packets and delta handoffs with quality comparison.
